# NAS-ENCLOSER
**so what i planing to do**

-I'm desinging a 3d printed encloser for my friend Nas system 
as i told you this model is design by me but the printing part is done by my frirnd because i not have 3d printer and hifi nas system :sob: 


  
so what my friend Nas Configuration:-

-1x Raspberry Pi 4 model B [RPI]

-2x USB3-to-SATA Adapter with 12V input (Poppstar Festplatten-Adapter (USB 3.1 Gen 1 Typ A) Sata USB Kabel für externe Festplatten)

-1x Fan 140x25mm [FAN]

-1x Industrial power supply 54 W, 6 A, 5/12 V (MEANWELL RD-50A) [PSU] 

-1x Fuse 5x20mm (LITT 02181.25MXP)

-1x Fuse Holder (Fuse holder FPG1 ø5x20mm) [FUSE_HOLDER]

-1x Power Rocker Switch (RND 210-00553) [SWITCH] 

-1x C14 plug (KES 1 S Cold-device built-in plug C14) [POWER_PLUG]

-2x DC Jacks 1.4mm Inner, 3.4mm outer diameters (NES/J 135)
